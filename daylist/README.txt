Daylist — React Todoアプリ

【開き方】
ZIPをすべて解凍し、html/index.htmlをブラウザで開いてください。
インストールや開発サーバーは不要です。

【機能】
タスクの追加・編集・完了・削除、優先度と期限、検索・絞り込み・並び替え。
再読み込みするとタスクはリセットされます。保存機能はありません。

【編集用ソース】
src/にReact・TypeScriptのソース、css/style.cssにスタイルがあります。
編集後はこのフォルダで npm install、npm run build を実行します。
Reactと必要なライブラリはjs/script.jsに同梱しています。
